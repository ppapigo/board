# 프로젝트 개요

## 목적

사용자가 게시판을 탐색하고 게시글과 이미지를 게시하며, 댓글·답글·좋아요/싫어요로 상호작용하고 관련 알림을 확인하는 커뮤니티 백엔드다. 관리자는 게시판을 관리한다.

## 현재 제공 기능

| 영역 | 기능 | 접근 |
|---|---|---|
| 인증 | 이메일 회원가입, 로그인, 로그아웃, 토큰 재발급 | 공개/쿠키 |
| 소셜 로그인 | Kakao 직접 연동, Spring OAuth2 기반 Kakao·Google | 공개 |
| 게시판 | 목록 조회, 생성·수정·삭제 | 조회 공개, 변경 ADMIN |
| 게시글 | 전체/게시판별/상세 조회, 작성·수정·삭제, 이미지 최대 5개 | 조회 공개, 변경 인증 |
| 댓글 | 루트 댓글·1단계 답글, 목록, 수정, 소프트 삭제 | 조회 공개, 변경 인증 |
| 반응 | 게시글·댓글 LIKE/DISLIKE 토글 | 인증 |
| 알림 | 댓글/답글 알림 목록, 읽음, 미읽음 수 | 인증 |
| 프로필 | 내 프로필 조회 | 인증 |

## 기술 스택

- Java 21, Spring Boot 3.5.14, Gradle
- Spring Web, Security, OAuth2 Client, Validation
- Spring Data JPA/Hibernate, MySQL
- JJWT 0.12.6, BCrypt, Lombok
- 로컬 파일 시스템 이미지 저장 및 `/images/**` 정적 제공

## 주요 사용자 역할

- 비회원: 게시판, 게시글, 댓글, 이미지 조회
- `USER`: 비회원 기능 + 글/댓글 작성, 본인 콘텐츠 수정·삭제, 반응, 알림, 프로필
- `ADMIN`: `USER` 기능 + 게시판 생성·수정·삭제

## 범위 밖 또는 미구현

- 프런트엔드 애플리케이션
- 게시글 검색, 정렬 UI 계약, 신고/차단, 북마크
- 프로필 수정, 비밀번호 재설정, 회원 탈퇴
- 게시글 수정 시 이미지 추가/삭제/재정렬
- 실시간 알림(WebSocket/SSE), 전체 읽음 처리
