# Board LLM Wiki

이 폴더는 현재 백엔드 구현을 기준으로 작성한 Obsidian 호환 프로젝트 위키이자, 향후 프런트엔드 요구사항의 기준점이다. 코드와 문서가 다르면 **코드가 현재 동작의 근거**이며, 목표 동작은 [[07-프런트엔드-요구사항]]과 [[08-결정사항과-알려진-이슈]]에서 관리한다.

## 한 문장 요약

JWT/소셜 로그인을 지원하며 게시판별 게시글, 이미지, 계층형 댓글, 게시글 반응과 알림을 제공하는 Spring Boot REST API다.

## 문서 상태 표기

- `current`: 코드에서 직접 확인한 현재 계약
- `proposed`: 프런트엔드 개발을 위한 제안 또는 목표
- `decision-needed`: 구현 전에 합의가 필요한 항목
- `deprecated`: 새 문서로 대체된 참고 자료

> [!warning] 보안
> `.env`, JWT 비밀값, OAuth client secret, 데이터베이스 암호는 위키에 복사하지 않는다. 현재 설정 파일에 하드코딩된 값은 [[08-결정사항과-알려진-이슈]]의 보안 항목을 따른다.
