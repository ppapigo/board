# 개발 가이드

## 사전 요구사항

- JDK 21
- MySQL, 로컬 DB `board`
- OAuth를 사용할 경우 Kakao/Google client 설정

## 설정

애플리케이션은 `.env`를 선택적으로 properties 형식으로 읽는다. 저장소의 실제 비밀값을 문서나 커밋에 포함하지 않는다.

필요 환경 변수:

```properties
KAKAO_REST_API=...
KAKAO_SECRET=...
KAKAO_CALLBACK=...
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
APP_UPLOAD_DIR=./uploads
```

현재 `application.yaml`의 DB 연결은 `localhost:3306/board`, 사용자 `root`로 고정되어 있다. 개발자별 설정과 운영 배포를 위해 환경 변수화하는 것이 필요하다.

## 실행과 검증

```powershell
.\gradlew.bat bootRun
.\gradlew.bat test
```

- 서버 포트: `8090`
- 이미지 디렉터리: 기본 `./uploads`
- 스키마: Hibernate `ddl-auto: update`
- 기본 테스트는 context 로딩, 반응 서비스, 회원가입·관리자 권한의 HTTP 통합 테스트와 라이브 이벤트·투표 상태의 DB 저장·재조회 검증을 포함한다.

### Redis Lua 회귀 테스트

`RedisLiveCounterStoreTest`는 실제 로컬 Redis를 사용한다. 전용 테스트 Redis를 실행하고 `TEST_REDIS_PORT`를 지정하면 좋아요 추가·취소, 사용자별 집계, 중복 투표 차단, 동시 요청, TTL을 검증한다. 환경 변수가 없으면 이 테스트만 건너뛴다.

```powershell
docker run --detach --rm --name board-redis-test -p 127.0.0.1:16379:6379 redis:7-alpine
$env:TEST_REDIS_PORT = '16379'
.\gradlew.bat test --rerun-tasks
docker stop board-redis-test
Remove-Item Env:TEST_REDIS_PORT
```

테스트는 매번 고유 ID를 사용하고 자신이 만든 키만 삭제한다. 운영 Redis를 테스트에 사용하지 않는다.

## 권장 최소 테스트

- 회원가입 중복, USER의 ADMIN 승격 차단
- 로그인/재발급/로그아웃 cookie 흐름
- 공개 GET과 보호된 쓰기 API의 401/403
- 작성자만 게시글·댓글 수정/삭제
- 이미지 타입·개수·크기 제한과 실패 시 정리
- 댓글 깊이/삭제/게시글 불일치 규칙
- 반응 생성/취소/전환과 집계
- 자기 활동 제외 알림, 소유자 읽음 처리
